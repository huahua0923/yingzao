# 构件稳定 ID 规则 v1

> 状态：**已定死**（步 1 产出，2026-10-12）。防的是**最要命的那条静默风险**：模型重出后构件 ID 变了，
> 叠加层的标注还在、却挂到了错的构件上（**症状静默**，界面看不出来，§4.3.1 / §6.7.1 / §10.6）。
> 可执行件：`tools/stable_id.py` · 判据 `gates/J-10.6-01_stable_id.py`。

## 1 病根（实测，不是推测）

现有 `data/buildings/*/floors/floor*.json` 里：

- 墙的 id 是**位置型** `w<层>-<序号>`（`w0-4`）；
- **门、柱大多根本没有 id**（`c001` 的 7 门 / 42 柱一个 id 都没有）。

位置型 id 的致命处：**只要在序号前面插入或删掉一件，其后所有 id 整体平移** —— 界面上标注还在，却挂到了隔壁墙上。

★ 更隐蔽的一点（本轮实测踩到）：这种「静默重挂」**用 id 集合差看不见**。在 `c001` F0 墙列表前面插一堵墙后，
位置型 id 集合只多了一个 `w0-142`，**差集几乎为空**；但 `w0-0 … w0-141` 这 **142 个 id 已经全部指向了别的墙**。
⇒ 判「有没有脱锚」**只能按 id 对齐、再比内容**，绝不能只比 id 集合（见 §4 的 `resolve_mapped`）。

## 2 ID 的形式

```
id = <campus>:<building>:<kind>:<h16>
h16 = sha256( kind + "|" + 各身份字段的规范序列化 ) 的前 16 个十六进制字符
```

- **不含**构件自己的 `id`、不含序号、不含任何位置量；
- 浮点先按容差 `QUANT = 1e-4 m`（0.1 mm）量化，再入哈希；`-0.0` 归一成 `0.0`。

## 3 身份字段（顺序即序列化顺序，**改顺序=改 ID**）

| kind | 身份字段 |
|---|---|
| `wall` | `type, thickness, height, poly, holes` |
| `door` | `x, y, w, h, outer, horiz` |
| `window` | `x, y, w, h, sill, horiz` |
| `column` | `x, y, w, d` |
| `elevator` | `x0, y0, x1, y1` |
| `stairwell` | `x0, x1, yBot, yTop, steps, pitch, type, axis` |
| `room` | 优先用图纸/台账房间号 `number`；无号则退回 `(floor, poly, purpose)` 的内容哈希 |

## 4 解析口径（脱锚怎么算）

`resolve_mapped(stored, current)`：两边都是 `{id: 内容键}`。

- `resolved`：同 id 且内容相同；
- ★ `reassigned`：同 id 但**内容变了** ⇒ **静默重挂**；
- `gone`：id 在上一版有、这一版没了；
- `added`：这一版新增的 id；
- ★ **脱锚条数 = `reassigned` + `gone`**。

对**内容型 id**，`id` 本身即内容 ⇒ `reassigned ≡ 0`，可用更简单的集合口径 `resolve`。
**位置型 id 必须用 `resolve_mapped`**，用集合口径必瞎。

## 5 取舍与未核项（写在这里，别忘）

- **取舍**：`thickness / height` 进身份 ⇒ 墙厚改一点点，该墙**脱锚**（报数、要人重锚）。
  这是**有意的**：宁可报「这条要重看」，也不静默挂到「看着像同一堵」的墙上。
- **未核**：`room.number` 自身跨重跑是否稳定，**本轮未核** ⇒ 房间 ID 的**否定判词**在核清前不算证据。
- **未做（属后续步）**：把 **DXF 实体 handle** 透传进 floors（比内容哈希更"语义稳定"，能扛住几何微调）。
  内容哈希是当前**够用且已实测**的方案；handle 透传列入 A1。

## 6 量具、正对照与盲区

- **量具**：`tools/stable_id.py`；单位=条；阈值=期望条数（由程序从实测数算出，不手打）。
- **正对照**（`gates/J-10.6-01_stable_id.py`，2026-10-12 实测**全红**，c001，1246 件）：

| 对照 | 读得 | 判词 |
|---|---|---|
| **C0 真重跑**（`recognize()` 重识别，out_dir 改指 scratch，不碰基线） | 重跑 1246 件 vs 基线 1246 件，脱锚 0 / 新增 0 | ✔ 同构件 ID **不变** |
| **C1 位置型**（F0 墙前插一堵） | 142 条 id 静默重挂（集合差只 +1） | ✔ 变红，证尺子有分辨力 |
| **C2 内容型**（同一扰动） | 脱锚 0、新增 1 | ✔ 稳 |
| **C3 改厚 2 倍**（真变一件） | 恰好 1 条脱锚 + 1 新增 | ✔ 「变了要报数」不是恒 0 |

- **盲区**：只认 §3 表里那几类件，对**新增构件种类全盲**；只读 `floor*.json`，对 GLB 里另生成的几何
  （屋面 / 女儿墙等）**全盲**；房间的稳定性受 §5「未核」限制。
