# 图线（线型 / 线宽）

## 线宽组

- 线宽基准 **b** 按图样复杂程度与比例选用，常用 b 系列：**0.35 / 0.5 / 0.7 / 1.0 / 1.4 / 2.0 mm**。
- 粗:中:细 = **b : 0.5b : 0.25b**（4:2:1）；GB/T 50104-2010 细分出「中粗 0.7b」。
- 简单图样可只用两种线宽（b : 0.25b）。
- 地平线可用 **1.4b**。

## 线型 → 用途对照

| 线型 | 线宽 | 用途 |
|------|------|------|
| 粗实线 | b | 平面/剖面中被剖切的**主要构造**轮廓（承重墙、柱断面）；立面外轮廓；剖切符号 |
| 中实线 | 0.5b | 被剖切的**次要构造**轮廓（墙身、台阶、散水、门扇开启线） |
| 细实线 | 0.25b | 尺寸线/尺寸界线、图例线、索引/标高符号、窗轮廓、家具线 |
| 中粗虚线 | 0.7b | 不可见轮廓线、拟建/扩建建筑轮廓 |
| 细单点长划线 | 0.25b | **定位轴线**、中心线、对称线 |
| 粗单点长划线 | b | 吊车轨道线 |
| 折断线 / 波浪线 | 0.25b | 断开界线 |

## 识别映射（资产图 DXF）

资产图 DXF **不携带线宽**，上述线宽语义失效。等效几何判据：

| 制图含义 | 几何判据（component_library 已固化） |
|----------|----------------------------------------|
| 承重墙（粗实线） | 墙皮双线间距 ∈ [wall_min, wall_max] 的闭合区域 |
| 柱断面（粗实线） | 独立小闭合多边形 / INSERT 块（_FZHK/_YZHK） |
| 门扇开启线（中实线） | 不闭合折线，最长段 ∈ [0.6, 3.0]m |
| 定位轴线（点划线） | 资产图通常**不画**，无需识别 |
| 不可见轮廓（虚线） | 资产图少用，忽略 |

> 关键：**线宽没了，就靠「闭合性 + 尺寸 + 图层前缀」替代线型语义**，这正是 derive_walls_and_outline 的设计依据。
