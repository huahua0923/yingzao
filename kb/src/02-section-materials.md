# 剖面材料图例

## 通用规定

- 剖面断面内应画材料图例；**未注明材料时用 45° 方向一致、间距均匀的细实线**。
- 同一形体各剖面的图例线方向/间距应一致；不同材料相接用粗实线隔开或斜线方向错开。
- 图例面积过大时，可沿轮廓线局部表示。
- 断面过小无法画图例时，可**涂黑**代替。

## 常见材料图例

| 材料 | 图例 | 备注 |
|------|------|------|
| 混凝土 / 钢筋混凝土 | 三角点 + 斜线；**断面小→涂黑** | 画出钢筋时不再画砼图例 |
| 普通砖 | 45° 斜线（或涂红/涂黑+说明） | 砌体 |
| 未指定材料 | 45° 细实线 | |
| 金属 | 斜线更密 | |

## 涂黑规范

- 相邻涂黑图例之间**必须留空隙**，净宽 ≥ 0.7mm（旧）/ 0.5mm（2010 版），不能连成一片。

## 识别映射（资产图 DXF）

- 资产图**很少画剖面材料图例**（它登记房间，不指导施工），所以 02 条对识别引擎主要价值是**负例**：
  - 若某层出现大面积「涂黑/45°斜线填充」实体 → 那是**楼板/地坪填充**，不是墙（area/length > 1），
    见 `derive_walls_and_outline` 的 `SLAB_RATIO` 判据：填充区当楼板足迹、不进墙 union。
  - 若图例线被误当墙段 → 会污染轮廓，需按「面积/周长比」剔除。
