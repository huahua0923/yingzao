# 门窗画法

## 编号与代号

- 门代号 **M**，窗代号 **C**；编号 M1/M2、C1/C2（或 M-1、C-1）。
- 同规格门窗各编一个号，便于统计门窗表。

## 门（平面图）

- 门扇 90° 或 45° 开启，**开启弧线宜绘出**。
- 开启方向线交角一侧 = 装合页一侧；**实线=外开、虚线=内开**。
- 门洞口画**中粗线**；开启方向线用中实线(0.5b)或细实线(0.25b)。
- 图例：单扇门、双扇门、对开折叠门、推拉门、弹簧门等。

## 窗（平面图）

- 窗轮廓用**细实线(0.25b)**：墙两皮之间画双线（窗框）+ 玻璃线。
- 图例：单层固定窗、单层外开平开窗、上悬窗等。

## 识别映射（资产图 DXF）—— 门的三种画法

| 楼 | 门在 DXF 里 | 识别方式 |
|----|-------------|----------|
| 理化楼 | 多点 LWPOLYLINE（>=10 点，含门扇+开启弧） | 点数阈值 |
| c006 | INSERT 块 $DorLib2D$（2 点单扇 / 17 点双扇） | 块插入点 + 点列 |
| c009 等 | 不闭合折线（门扇线 0.6~3.0m） | `detect_doors`：最长段落在门宽区间 |

**统一结论（component_library 已固化）**：门 = 墙的**缺口**，不是洞。识别门只需抓住
「开启方向 + 门宽」，门宽 = 点列/折线里的**最长段**（门垛短段不干扰）。

## 窗的合成

- 资产图 DXF **无窗数据**，窗是**合成数据**：沿外墙立面按 `facade_windows`
  （间距/宽度/窗台/高度由 spec 定）等距布置，属「美观建模」而非「读图」。
