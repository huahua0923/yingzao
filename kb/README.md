# CAD 识图知识库（作图标准）

> 目标：把「建筑制图国标 + 高校资产测绘图实测约定」沉淀成可检索、可被识别引擎消费的结构化知识，
> 反哺 `backend/recognizer/` 与 `component_library.py`（构件库），让每一栋楼的识别都站在「建筑制图规范」
> 的高度上做，而不是靠临场猜几何。

## 为什么做

- 用户铁律：**「剖面和实际的图达到 95% 以上」「最终生成的是漂亮的建筑，不是乱七八糟的块体」**。
- 识别引擎目前靠几何启发式（墙=闭合双线、门=开口跨度、楼层=Y 聚类 gap）硬扛，缺一套「制图规范 → 识别规则」
  的正向映射。本知识库补这一层：**规范怎么说 → DXF 里长什么样 → 识别怎么判**。
- 资产图 DXF 由 ODA File Converter 转出，**不携带线宽/颜色/图层中文名**（层名带代理项会乱码），
  因此不能直接套「粗实线=承重墙」的线宽语义，只能靠几何 + 图层数字前缀。

## 目录结构

```
kb/
├── README.md        # 本索引
├── manifest.json    # 机器索引（标题/标准/标签/关键结论/识别映射/关联构件库函数）
├── build_kb.py      # 管线：src/*.md + manifest.json → kb.json（结构化、可被 Python 加载）
├── kb.json          # 构建产物（识别引擎消费）
└── src/             # 知识源（markdown，一文件=一主题）
    ├── 00-overview.md               # 制图标准总览
    ├── 01-line-types.md             # 图线（线型/线宽）
    ├── 02-section-materials.md      # 剖面材料图例
    ├── 03-door-window.md            # 门窗画法
    ├── 04-stair.md                  # 楼梯画法
    ├── 05-dimension-annotation.md   # 尺寸标注
    ├── 06-grid-axes.md              # 定位轴线
    └── 07-asset-survey.md           # 高校资产图实测约定（本项目专属）
```

## 两条知识链（规范 ↔ 实测）

| 层 | 内容 | 载体 |
|----|------|------|
| 理论 | GB/T 50001-2017《房屋建筑制图统一标准》、GB/T 50104-2010《建筑制图标准》 | `src/00..06` |
| 实测 | 高校国资处资产管理图（理化楼/11 栋教学楼）的绘图约定、编码坑、层名坑 | `src/07` + `component_library.py` |

## 关键结论速查

- **线宽组** b : 0.5b : 0.25b（粗:中:细 = 4:2:1），2010 版细分中粗 0.7b。
- **粗实线** = 剖切到的主要构造（承重墙/柱断面）；**中实线** = 次要构造（墙身/台阶/门扇开启线）；**细实线** = 尺寸/图例/窗轮廓。
- **点划线(细)** = 定位轴线/中心线；**中粗虚线** = 不可见轮廓/拟建建筑。
- **剖面材料**：砼/钢筋混凝土断面小 → **涂黑**；砖 → **45° 斜线**；未注明材料 → **45° 细实线**；相邻涂黑间隙 ≥0.7mm。
- **门窗**：门代号 M、窗代号 C；门开启弧 45°/90°、实线外开/虚线内开；窗=双线+玻璃线。
- **楼梯**：踏步线每格一级、折断线 45°、「上/下」长箭头、梯段边双线=栏杆。
- **资产图坑**（本项目实测，见 `src/07`）：层名乱码、中文编码混杂(GBK/UTF-8)、门=INSERT 块、墙=LINE/LWPOLYLINE 两套。
