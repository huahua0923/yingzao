# 只做「读 1-bit 掩膜 + 纯 numpy 寻路」，不做任何栅格化 ——

# ★★ 为什么钉在 1.26 而不是 2.x（2026-10-01 实测，两条都测过）：
#   · 202.115.132.14 是 QEMU 虚机（`model name: QEMU Virtual CPU version 2.5+`），
#     CPU **没有 AVX2**；而 numpy 2.x 的官方 manylinux wheel 是按 **x86-64-v2** 基线编的
#     ⇒ 装得上，但 `import numpy` 当场崩：
#       RuntimeError: NumPy was built with baseline optimizations: (X86_V2)
#                     but your machine doesn't support: (X86_V2).
#     （同一个 venv 里 fastapi/uvicorn/pydantic/pydantic_core/psycopg[binary] 全部
#       import 正常 —— **只有 numpy 2.x 中招**，所以这不是「这台机器不能用 wheel」。）
#   · numpy 1.26.4（最后一个 1.x，wheel 按通用 x86-64 基线编）在这台机上
#     实测 `import numpy → numpy 1.26.4 OK`。
#   · numpy **不在 API 的启动路径上**：`rooms.py:335` 是函数内懒加载
#     （`from build_path import compute_path`），缺依赖回 503 —— 所以就算这条
#     钉错了，倒的也只是 /api/path 一个路由，不是整个服务。
numpy==1.26.4
