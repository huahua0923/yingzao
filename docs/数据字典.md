# 数据字典

## 1 模型包 `manifest.json`

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `schema` | string | 是 | 包格式版本 |
| `campus_id` | string | 是 | 数据域，如 `cdut-main` |
| `building_id` | string | 是 | 楼栋稳定 ID |
| `title` | string | 是 | 楼栋展示名 |
| `lod` | object | 是 | 标准、等级、关系、引用 |
| `model` | object | 是 | 主模型路径、字节数、哈希 |
| `qc` | object | 是 | 质检报告引用和结论 |
| `layers` | array | 否 | 楼层、构件、房间索引 |

## 2 房间台账

| 字段 | 类型 | 说明 |
|---|---|---|
| `room_id` | string | 稳定房间 ID |
| `building_id` | string | 楼栋 ID |
| `floor` | string | 楼层 |
| `room_no` | string | 房间号 |
| `use` | string | 用途 |
| `area_m2` | number | 图上面积 |
| `source` | string | 来源文件与版本 |

## 3 判据台账

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 判据 ID |
| `script` | string | 判据文件 |
| `rc` | integer | 0 通过 / 1 缺 / 4 没量到 |
| `secs` | number | 最近一次耗时 |
| `when` | string | 最近一次实跑时间 |

## 4 发布清单

| 字段 | 类型 | 说明 |
|---|---|---|
| `schema` | string | `cdut3d-release/1` |
| `profile` | string | 发布档 |
| `git_commit` | string | 源版本 |
| `files[].path` | string | 相对路径 |
| `files[].bytes` | integer | 字节数 |
| `files[].sha256` | string | 文件哈希 |

## 5 数据质量

质量检查至少覆盖：

- 完整性：发布清单中的文件都在。
- 一致性：哈希、字节数、模型包 manifest 对得上。
- 可追溯性：每个包能追到判据和 Git 提交。
- 时效性：台账带最近实跑时刻。
- 可访问性：`/live`、`/health` 可探。
- 规范性：ID、CRS、LOD、文件命名符合规范。
