# 主数据与权威源

| 主数据 | 唯一权威源 | 消费方 | 说明 |
|---|---|---|---|
| 楼栋档案 | `rebuild/构件库/楼栋.json` | 工作台、生产链 | 楼栋名、层数、源图 |
| 构件参数 | `rebuild/构件库/参数.json` | 流程台、生产链 | 参数值和依据 |
| 房间库 | `rebuild/构件库/房间库.json` | 工作台、展示 | 房间号、用途、面积 |
| 图纸库 | `rebuild/构件库/图纸库.json` | 工作台 | 每层 DXF |
| 模型包 | `packs/cdut-main/<bid>/manifest.json` | 查看器、服务器 | 交付件 |
| 判据输出 | `gates/_out/*.json` + `_ledger.json` | 工作台、验收 | 最近一次实测 |
| 发布清单 | `release-manifest.json` | 运维、审计 | 部署版本 |

## 规则

1. 页面读数从权威源现场读，不手抄第二份。
2. 机器写的数据只进 `observed/`、`gates/_out/`、发布清单。
3. 人写声明只进 `registry/栈.json`、规范文档。
4. 同一量有两个口径时，键名必须带口径。
