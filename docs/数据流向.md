# 数据流向

```text
原始 CAD/DXF
  → 01_cad 源图
  → 02_recognize 识别 JSON
  → 03_redraw 重画 DXF
  → 05_build 建件
  → 06_su / FreeCAD → GLB
  → packs/<campus>/<building>/manifest.json
  → release-manifest.json
  → 服务器只读展示

航拍原片 + POS + 控制点
  → RealityCapture/COLMAP 空三
  → 稠密点云/网格/纹理
  → 3D Tiles / Potree
  → 实景层发布
  → 与白模同机位叠加

判据
  → 每步输出 *_out/*.json
  → 汇总 _ledger.json
  → 工作台/验收页
```

## 边界

- 原片、位姿、控制点只留本地。
- 服务器只接收切片结果和已验收包。
- 模型包与判据报告必须同批发布。
- 任何人工修改必须留下改动记录和复跑结果。
