# cdut3d 需求规格

## 1 项目目标

把校园 CAD 图纸、航拍实景和建筑模型组织成可查询、可展示、可扩展的三维数字底座。系统同时服务两类场景：

- **展示**：校园建筑外观、楼层、房间用途、实景对照。
- **生产**：本地完成图纸识别、构件生成、质检、打包和发布。

## 2 使用对象

| 角色 | 需求 |
|---|---|
| 校方管理人员 | 查看楼栋、楼层、房间与统计，核对模型与图纸 |
| 建模人员 | 在本地运行生产链，查看判据与缺陷 |
| 展示访客 | 浏览三维校园、切换楼层、查看房间信息 |
| 运维人员 | 部署、探活、回滚、看日志和发布清单 |

## 3 范围内

- 建筑白模、楼层、房间、构件和模型包。
- 本地 CAD/DXF 识别与建模。
- 本地倾斜摄影处理与实景瓦片接入。
- Web 查看器、工作台、流程台、对照页、判据页。
- 模型包发布、版本清单、服务器只读装载。
- 数据字典、接口、部署、安全和归档材料。

## 4 范围外

- 不在服务器运行 AutoCAD、Blender、FreeCAD、RealityCapture、COLMAP。
- 不在服务器存原始航拍、不做 SfM/MVS、不做切片。
- 不以倾斜摄影替代可剖切、可点房间构件的室内模型。
- 本阶段不建设完整统一身份认证；生产管理端先用 Nginx 基础认证 + 校内网络/VPN。
- 本阶段不承诺模型达到厘米级实景精度；精度以控制点和判据实测为准。

## 5 关键约束

1. 本地算，服务器只展示。
2. 模型包必须带质检报告和 LOD 声明。
3. 同一输入重跑，构件 ID 应稳定。
4. 服务器只接收已验收发布包。
5. 测试与演示数据不得含真实师生个人信息。
6. 所有发布必须可回滚。

## 6 验收摘要

- 三维页面可打开，模型加载完成。
- 工作台、流程台、判据页的主要路由可用。
- 发布包 `verify` 返回 0。
- `/live` 与 `/health` 返回 200。
- 管理接口未认证时不可访问。
- 最近一次判据台账无“没量到”被写成通过。
