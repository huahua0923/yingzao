# 验收判据

## 1 数据与模型

- [ ] 包内 `manifest.json` 含 `campus_id`、`building_id`、`lod`、模型文件和质检报告。
- [ ] 模型包通过 `tools/modelpack.py` 验证。
- [ ] 同输入重跑，构件稳定 ID 符合 `规范/构件稳定ID规则-v1.md`。
- [ ] 判据台账中“缺”和“没量到”都有明确结论，不混为通过。

## 2 展示

- [ ] `/` 打开后能看到三维场景。
- [ ] 楼栋可切换，楼层可切换，房间可点选。
- [ ] 大 GLB 加载后，内存不随并发请求线性翻倍。
- [ ] 控制台无阻断性错误。

## 3 部署

- [ ] `deploy/scripts/release.py verify <dir>` 返回 0。
- [ ] `/live` 返回 200。
- [ ] `/health` 返回 200 且四个检查项都为真。
- [ ] 管理端未认证返回 401。
- [ ] 服务只监听 `127.0.0.1:8150`。
- [ ] HTTPS 证书有效，HTTP 自动跳转。

## 4 安全

- [ ] 仓库无 `.env`、私钥、口令。
- [ ] 管理端仅校园网/VPN 可达。
- [ ] 上传与写接口有大小限制和限速。
- [ ] 审计日志可按人、按时间查询（当前待办）。

## 5 运维

- [ ] 发布目录有 `release-manifest.json` 和 SHA-256。
- [ ] 回滚到上一版本已演练并留记录。
- [ ] 备份保留至少 6 个月（一级项目审计要求）。

## 6 结论口径

“页面能开”不等于验收通过。每条判据必须有实测输出、时间和验证人。
