# 信创适配清单

## 1 当前服务器侧

| 项 | 当前 | 信创可行性 | 结论 |
|---|---|---|---|
| 语言 | Python 3.12 | 鲲鹏/飞腾/龙芯 + 统信/麒麟可运行 | 需在目标环境复测 |
| Web 服务 | Python 标准库 HTTP | 纯 Python，可移植 | 高 |
| 前端 | Three.js/WebGL2 | 依赖浏览器，不依赖 CPU 指令集 | 高 |
| 数据存储 | JSON/GLB/静态文件 | 无数据库绑定 | 高 |
| Nginx | 通用 | 国产 OS 有替代/移植 | 高 |

## 2 本地生产侧

| 工具 | 约束 |
|---|---|
| AutoCAD | Windows 商业软件，信创桌面不可用 |
| Blender | 有 Linux 版，可在国产 Linux 评估 |
| FreeCAD | 有 Linux 版，可在国产 Linux 评估 |
| RealityCapture | Windows/NVIDIA 依赖强 |
| 3ds Max / SketchUp | Windows 商业软件 |

## 3 结论

- **服务器展示侧可优先信创**：Python、Nginx、静态资源不绑定 Windows。
- **本地生产侧暂不强求信创**：重依赖商业 Windows 工具，需另立替代方案。
- 上线前需在目标 CPU/OS 上实测 `/live`、`/health`、GLB 加载和中文路径。
