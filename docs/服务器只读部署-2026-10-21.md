# 服务器只读部署（营造 · 成都理工大学）

## 当前部署

- 访问地址：`https://202.115.132.14/`
- 认证：登录页账号由用户指定；口令只以 scrypt 派生值存在，不写入仓库。
- 运行模式：`CDUT3D_MODE=viewer`
- 应用监听：`127.0.0.1:8150`
- Nginx：80 端口 301 到 HTTPS；443 终止 TLS 后反代 Python
- 发布目录：`/srv/cdut3d/releases/<时间戳>`
- 当前版本：`/srv/cdut3d/current`
- 服务：`cdut3d.service`

服务器只提供：

- 登录页
- 三维模型首页
- 房屋信息与统计页 `/info`
- `/packs/` 下的只读模型包

本地工作台、流程台、判据页、重跑接口在 viewer 模式下全部返回 404，不参与生产发布。

## TLS

当前没有域名，使用 IP SAN 自签名证书：

```text
/etc/cdut3d/tls/fullchain.pem
/etc/cdut3d/tls/privkey.pem
```

浏览器首次访问会提示证书不受信任。后续有正式域名后，替换证书并修改
`/etc/nginx/conf.d/cdut3d.conf` 的 `server_name` 即可。

## 增量发布

只改页面/服务代码时，可以替换 `current` 下的少量文件，然后重算发布清单：

```bash
python3 /srv/cdut3d/current/deploy/scripts/viewer_release.py refresh /srv/cdut3d/current
python3 /srv/cdut3d/current/deploy/scripts/viewer_release.py verify /srv/cdut3d/current
systemctl restart cdut3d
```

模型包更新时，替换 `packs/cdut-main/<bid>/`，再执行同一套 refresh/verify/restart。

## 本机构建

```powershell
python -X utf8 deploy\scripts\viewer_release.py build C:\tmp\cdut3d-viewer
python -X utf8 deploy\scripts\viewer_release.py verify C:\tmp\cdut3d-viewer
python -X utf8 deploy\scripts\viewer_release.py archive C:\tmp\cdut3d-viewer C:\tmp\cdut3d-viewer.tar.gz
```

发布包只包含 `workbench/server.py`、登录/三维/房屋信息页面、`demo/vendor`、
`demo/building.html`、`demo/index.html`、`packs/` 和部署脚本，不包含本地工作台、重建中间件、原片和归档。
