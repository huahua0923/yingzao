## 2 发现

| 级别 | 发现 | 结论 |
|---|---|---|
| 高 | 服务无认证，若 `--host 0.0.0.0` 直接公网暴露，写接口可被任意访问 | 不允许直接暴露；Nginx 认证 + VPN |
| 高 | `_mount()` 原实现整件读文件 | 已改为流式 + ETag |
| 中 | 原 `_same_origin()` 只允许 localhost，生产域名 POST 会被误拒 | 已改为 Host 同源比较 |
| 中 | `ThreadingHTTPServer` 线程数无上限 | 仅绑本机；Nginx 限速，公网不直连 |
| 中 | 若干 `except Exception` 只回退不记录 | 几何展示可接受；写操作需补结构化日志 |
| 中 | 上传接口只限制大小，不限制并发 | 生产 Nginx 限速、认证；后续加任务队列 |
| 低 | 静态页无 CSP | 先由 Nginx 加 `nosniff`、`SAMEORIGIN`、`Referrer-Policy` |
| 低 | 部分脚本硬编码 Windows 路径 | 本地生产可接受；发布脚本只用相对路径 |

## 3 已确认的安全正面

- `_safe_join()` 使用 `realpath` 前缀校验，挡 `..`、反斜杠、绝对路径和盘符穿越。
- 写参数使用校验、备份、原子替换、回读。
- 大文件 `/files/` 已流式发送。
- `pipeline/server.py` 的独立入口已由工作台复用，不再需要额外开放 8800。

## 4 上服务器前必须完成

1. Python 只绑 `127.0.0.1`。
2. Nginx 启用 HTTPS、基础认证、限速。
3. 管理端只经校园网/VPN 访问。
4. `/live`、`/health` 纳入监控。
5. 发布目录只读，状态目录单独可写。
