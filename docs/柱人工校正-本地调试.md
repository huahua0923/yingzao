# 柱人工校正（本地调试）

> 这是人工调试工具，不写入 `参数.json`，也不进入统一需求或统一标准。

## 为什么需要

源图 `4.1结构柱` 图层中的闭合多段线是柱候选，但“图上画了”不等于“这一层实际有”。
c001 的 `5层-柱-054` 就是用户现场确认不存在、而源图层确实画出的例子。

仅凭跨层位置或楼板距离自动删柱并不可靠：

- 柱可能在低层存在、上层不存在；
- 也可能穿过开放中庭或外廊，本层楼板没有覆盖；
- 同一张图可能把低层柱作为参考图元保留。

因此自动规则只负责“识别到候选”，最终取舍走人工校正表。

## 页面

本地工作台：

```text
http://127.0.0.1:8150/column-review?bid=c001
```

工作台左侧导航“柱 · 人工校正”，或楼栋详情页右上角“柱子人工校正”也可进入。

页面支持：

- 按楼栋、楼层查看柱与墙的平面关系；
- 点击柱切换“保留 / 排除”；
- 新增模式点击平面补充漏识别的柱；
- 保存到独立文件 `rebuild/构件库/柱人工校正.json`。

## 生效方式

保存后，从“建件”重跑该楼：

```powershell
python -X utf8 -I rebuild/tools/run_chain_bid.py c001 --from 建件
```

`build3d.py` 与 `export_contours.py` 共用同一份人工校正表；排除按楼层 + 柱中心 20 mm
容差匹配，新增柱按中心与宽深生成矩形柱。
