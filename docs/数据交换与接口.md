# 数据交换与接口

## 1 静态资源

| 路径 | 类型 | 说明 |
|---|---|---|
| `/demo/` | HTML/JS/CSS | Three.js 查看器 |
| `/packs/` | JSON/GLB | 已验收模型包 |
| `/reality/` | 3D Tiles | 已验收实景层 |
| `/process/` | GLB/PNG | 实景分层与对照 |
| `/rebuild/` | GLB/OBJ | 参照件 |

## 2 健康接口

| 方法 | 路径 | 返回 |
|---|---|---|
| GET | `/live` | 进程存活 |
| GET | `/health` | UI、工作台、包索引、判据输出四项检查 |

## 3 工作台 API

主要读接口：

- `GET /api/overview`
- `GET /api/building?bid=<id>`
- `GET /api/params`
- `GET /api/state`
- `GET /api/criteria`

写接口：

- `POST /api/params/save`
- `POST /api/profile/save`
- `POST /api/room/save`
- `POST /api/run`
- `POST /api/quick3d`

写接口必须 `application/json`（上传接口除外），并只允许同源请求。

## 4 发布包接口

发布包根目录必须有 `release-manifest.json`。服务器只接受 `verify` 通过的发布目录。

## 5 错误口径

- `400`：参数或请求体不合法。
- `401`：管理端未认证（Nginx）。
- `403`：跨源/路径越界。
- `404`：件不在。
- `429`：已有任务在跑或触发限速。
- `500`：服务端异常，必须带日志。
- `503`：健康检查失败。

## 6 三维交换

- 白模：GLB/glTF。
- 实景：3D Tiles（tileset.json + b3dm/glb）。
- 坐标：白模 EPSG:4544 + 椭球高；实景按 ENU/ECEF 变换对齐。
- 所有交换件必须带版本、哈希和坐标基准。
